# Resumo (drill-down) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tela `/resumo` com os lançamentos que formam qualquer soma do app, aberta por links em todas as somas por grupo.

**Architecture:** O filtro vive no endereço. `lib/resumo.ts` (puro, testado) lê e monta o filtro e decide quais lançamentos entram por regra; `app/resumo/page.tsx` busca no período e aplica o filtro; cada tela troca o texto da soma por um `Link` montado com `linkResumo`.

**Tech Stack:** Next.js 16, Supabase JS, Tailwind v4, Vitest, Recharts.

**Spec:** `docs/superpowers/specs/2026-10-24-resumo-design.md`

## Global Constraints

- Regras `resultado`, `503020` e `conta` exatamente como no spec. A `503020` reaproveita a classificação de `lib/regra503020.ts` (grupo da subcategoria; aplicação em conta de investimento conta como `investimento`).
- `voltar` só é aceito se começar com `/` e não com `//`.
- Links: linha inteira tocável, `min-h-11`, setinha "›" (`aria-hidden`), cores dos valores iguais às de hoje.
- Textos: "Nenhum lançamento encontrado para este filtro.", "Carregando...", "Editar", "Voltar".

## Review Focus

- Filtro "Sem categoria" (`categoria=sem`) — traz só os lançamentos sem categoria. Teste na Task 1.
- Aplicação de conta corrente para conta de investimento com `grupo=investimento` — entra; resgate não entra. Teste na Task 1.
- Lançamento neutro ou com `fatura_cartao_id` na regra `resultado` — não entra; na regra `conta` entra. Teste na Task 1.
- `voltar=//site.com` — ignorado, volta para `/transacoes`. Teste na Task 1 (`caminhoVoltarSeguro`).
- Período de vários meses — média por mês = total ÷ número de meses de competência do período. Teste na Task 1.

### Task 1: `lib/resumo.ts`

**Files:** Create `lib/resumo.ts`, `lib/resumo.test.ts`

**Interfaces — Produces:**
- `type RegraResumo = 'resultado' | '503020' | 'conta'`
- `type FiltroResumo = { de: string; ate: string; regra: RegraResumo; tipo?: 'receita'|'despesa'; categoria?: string; subcategoria?: string; categorias?: string[]; grupo?: 'necessidade'|'desejo'|'investimento'|'deducao'|'sem'; escopo?: 'familiar'|'pessoal'; membros?: string[]; conta?: string; cartao?: string; movimento?: 'rendimento'|'aporte_empresa'|'aplicado'|'resgatado'; titulo?: string }`
- `type LancamentoResumo = { id; data; descricao; valor: number; tipo; status; escopo; dono_id; categoria_id; subcategoria_id; conta_id; cartao_id; transferencia_id; fatura_cartao_id; neutro: boolean; movimento_investimento }` + `CAMPOS_LANCAMENTO_RESUMO` (string de select, com `categorias(nome), subcategorias(nome), contas(nome), cartoes_credito!cartao_id(nome)`)
- `linkResumo(f: FiltroResumo): string` → `/resumo?…` (omite vazios; listas com vírgula)
- `lerFiltroResumo(p: URLSearchParams): FiltroResumo | null` (null sem `de`/`ate`)
- `entraNoResumo(l, f, ctx: { grupoDaSubcategoria: Map<string, string|null>; tipoDaConta: Map<string,string>; contaDaTransferencia: Map<string, { origem: string|null; destino: string|null }> }): boolean`
- `mesesDoIntervalo(de: string, ate: string): number` (meses de competência distintos)
- `caminhoVoltarSeguro(v: string | null): string` (padrão `/transacoes`)

- [ ] Testes: link ida-e-volta (`lerFiltroResumo(new URLSearchParams(linkResumo(f).split('?')[1]))` igual a `f`); `categoria=sem`; regra `resultado` exclui neutro/transferência/fatura agregada/pendente; regra `conta` inclui transferência e neutro da conta; `grupo=investimento` inclui aplicação corrente→investimento e exclui resgate; `grupo=sem` pega despesa com subcategoria sem grupo e sem subcategoria; `membros` aceita familiar quando lista inclui `__familiar__`; `movimento=aplicado` = transferência receita na conta; `mesesDoIntervalo('2026-04-26','2026-10-25')` = 6; `caminhoVoltarSeguro('//x.com')` = `/transacoes`, `('/resumo?de=1')` = `/resumo?de=1`.
